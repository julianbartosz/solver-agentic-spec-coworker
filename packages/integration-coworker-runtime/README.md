# integration-coworker-runtime

Lightweight runtime library for API clients generated by [Integration Coworker](https://github.com/julianbartosz/solver-agentic-spec-coworker).

## Installation

```bash
pip install integration-coworker-runtime
```

## Quick Start

Generated clients automatically use this library. Just install it in your project:

```python
# Example generated client usage
from integrations.clients.stripe import StripeClient

client = StripeClient(api_key="sk_test_...")
result = client.create_checkout_session(payload={
    "line_items": [{"price": "price_123", "quantity": 1}],
    "mode": "payment",
})
```

## Manual Usage

You can also use the runtime components directly:

```python
from integration_coworker_runtime import (
    IntegrationClient,
    BearerAuth,
    ExponentialRetry,
    TokenBucketRateLimiter,
)

# Create a client with policies
client = IntegrationClient(
    base_url="https://api.example.com/v1",
    auth=BearerAuth(env_var="EXAMPLE_API_KEY"),
    retry=ExponentialRetry(max_attempts=3, base_delay=1.0),
    rate_limiter=TokenBucketRateLimiter(rps=10, burst=20),
)

# Make requests
response = client.post("/users", json={"name": "Alice"})
```

## Components

### Authentication

- `NoAuth` - No authentication
- `BearerAuth` - Bearer token (OAuth2, JWT)
- `ApiKeyAuth` - API key in header
- `BasicAuth` - HTTP Basic authentication

### Retry Strategies

- `NoRetry` - No retry, fail immediately
- `ExponentialRetry` - Exponential backoff with jitter

### Rate Limiters

- `NoRateLimiter` - No rate limiting
- `TokenBucketRateLimiter` - Token bucket algorithm
- `SlidingWindowRateLimiter` - Sliding window counter

### HTTP Client

- `IntegrationHttpClient` - Simple HTTP client with built-in retry and auth
- `IntegrationClient` - Full-featured client base class

### Exceptions

- `IntegrationError` - Base exception for all integration errors
- `TransientIntegrationError` - Retryable errors (429, 5xx, network)
- `AuthIntegrationError` - Authentication failures (401, 403)

## Environment Variables

Auth handlers can read credentials from environment variables:

```python
# Reads from STRIPE_API_KEY environment variable
auth = BearerAuth(env_var="STRIPE_API_KEY")

# Or provide directly (not recommended for production)
auth = BearerAuth(token="sk_test_...")
```

# Operations

This section is the **operator runbook** for running Integration Co-Worker in real environments.

It focuses on:

- Deploying the app (local Docker Compose and cloud)
- Managing the production database (Postgres + pgvector)
- Running production validation checks and smoke tests

If you’re looking for end-user onboarding, start with **Getting Started** in the main docs navigation.

If you’re operating or deploying the system, start with **Ops Runbook → Getting Started (Ops)**.
